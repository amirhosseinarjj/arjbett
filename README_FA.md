# ARJBETT — نسخه تحلیل تاریخی غیرشرط‌بندی

این برنامه یک داشبورد آموزشی برای بررسی داده‌های گذشته فوتبال است. هیچ انتخاب برنده، احتمال برد/مساوی/باخت، ضریب، مبلغ یا توصیه شرط‌بندی تولید نمی‌کند.

## امکانات
- داشبورد فارسی و واکنش‌گرا
- ورود نتایج مسابقات از فایل CSV و ذخیره در SQLite
- نمایش مسابقات ثبت‌شده و خلاصه تعداد بازی‌ها، تیم‌ها و گل‌ها
- نمایش فرم پنج بازی اخیر و مقایسه امتیازهای دو بازه تاریخی
- مقایسه دو تیم بر اساس فرم اخیر، گل‌های زده/خورده و نتایج رودررو
- امکان نمایش داده نمونه برای آزمایش رابط کاربری (داده نمونه واقعی نیست)
- همگام‌سازی اختیاری با football-data.org، فقط برای دریافت نتایج و برنامه مسابقات

## اجرا در ویندوز
1. Python 3.10 یا جدیدتر نصب باشد.
2. وارد پوشه `backend` شو.
3. در ترمینال اجرا کن:
   `py -m venv .venv`
   سپس:
   `.venv\\Scripts\\activate`
4. نصب وابستگی‌ها:
   `pip install -r requirements.txt`
5. اجرای سرور:
   `uvicorn main:app --reload`
6. مرورگر را باز کن:
   `http://127.0.0.1:8000`

## استفاده بدون API
برای شروع، دکمه «نمایش داده نمونه» را بزن. این داده‌ها ساختگی‌اند و فقط برای تست رابط کاربری هستند.
برای تحلیل واقعی، فایل CSV نتایج مسابقات خودت را با ستون‌های زیر وارد کن:

`date,competition,home_team,away_team,home_goals,away_goals,status`

نمونه:
`2026-10-25,PL,Arsenal,Chelsea,2,1,FINISHED`

تاریخ را به شکل `YYYY-MM-DD` و وضعیت بازی پایان‌یافته را `FINISHED` وارد کن.

## اتصال زنده اختیاری
بدون توکن هم می‌توانی از CSV و داده نمونه استفاده کنی. اگر بعداً خواستی داده‌های زنده را از football-data.org بگیری، توکن باید فقط روی سرور و در متغیر محیطی `FOOTBALL_DATA_TOKEN` قرار بگیرد؛ آن را داخل فایل HTML یا مرورگر وارد نکن.
در PowerShell:
`$env:FOOTBALL_DATA_TOKEN="YOUR_TOKEN"`
سپس سرور را اجرا کن. پوشش رقابت‌ها و فیلدهای داده به سطح دسترسی API بستگی دارد.

## مسیرهای API محلی
- `GET /api/health`
- `GET /api/matches`
- `POST /api/import/csv`
- `GET /api/teams`
- `GET /api/teams/{team}/form`

## محدودیت تحلیل
مقایسه‌ها بر اساس نتایج ثبت‌شده در پایگاه داده هستند. کیفیت گزارش به کامل و به‌روز بودن داده‌ها وابسته است. این برنامه نتیجه مسابقه آینده یا احتمال برد، مساوی و باخت را پیش‌بینی نمی‌کند.


## اجرای آسان در ویندوز
بعد از خارج‌کردن ZIP، روی فایل `شروع-ARJBETT.bat` دوبار کلیک کن. بار اول کتابخانه‌ها نصب می‌شوند و مرورگر باز می‌شود. پنجره سرور را تا وقتی از سایت استفاده می‌کنی نبند. برای توقف، در همان پنجره `Ctrl+C` را بزن.

## انتشار آنلاین برای باز کردن با موبایل (Render)
این پروژه اکنون فایل `render.yaml` برای استقرار روی Render دارد. برای انتشار عمومی باید خودت با حساب کاربری وارد سرویس میزبانی شوی و مخزن GitHub را متصل کنی؛ من به حساب‌های بیرونی تو دسترسی ندارم و نمی‌توانم بدون ورود و اجازه‌ات دامنه عمومی بسازم.

1. فایل ZIP را از حالت فشرده خارج کن.
2. پوشه `ARJ_Football_AI_NonBetting` را در یک مخزن جدید GitHub بارگذاری کن.
3. در Render گزینه **New + → Blueprint** را انتخاب و مخزن GitHub را وصل کن.
4. Render فایل `render.yaml` را پیدا می‌کند؛ سرویس را ایجاد کن و منتظر پایان Deploy بمان.
5. آدرس `https://...onrender.com` که Render می‌دهد، لینک وب‌اپ توست.
6. برای داده زنده، در تنظیمات سرویس Render متغیر محیطی `FOOTBALL_DATA_TOKEN` را با توکن API خودت اضافه کن.

نکته: پلن رایگان Render ممکن است پس از بی‌فعالیتی سرویس را موقتاً بخواباند و فضای دیسک پایدار نداشته باشد؛ بنابراین اطلاعات CSV/SQLite ممکن است بعد از راه‌اندازی مجدد یا Deploy باقی نماند. برای نگهداری دائمی داده‌ها به دیسک پایدار یا پایگاه‌داده مدیریت‌شده نیاز است.

## افزودن به صفحه اصلی آیفون
پس از انتشار، لینک `onrender.com` را در Safari باز کن → دکمه Share (مربع با فلش رو به بالا) → **Add to Home Screen** → Add. آیکون ARJBETT روی صفحه اصلی ظاهر می‌شود.
